# Md. Rakibul Hasan — Portfolio

> A modern developer portfolio built with React, TypeScript, and a component-based architecture.

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- CSS3
- Intersection Observer API

## ✨ Features

- Interactive Bash-style terminal
- Responsive design
- Scroll reveal animations
- Custom cursor
- Experience & skills sections
- Projects showcase
- Competitive programming section
- AI & engineering focus

## 📁 Architecture

```text
src/
├── components/   # Reusable UI components
├── sections/     # Portfolio sections
├── hooks/        # Custom React hooks
├── data/         # Portfolio content
├── assets/       # Images & assets
├── App.tsx
└── main.tsx

🛠️ Run Locally
npm install
npm run dev
